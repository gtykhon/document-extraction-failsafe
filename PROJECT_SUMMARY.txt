================================================================================
KEY FEATURES
================================================================================

Extraction Cascade:
  1. PyPDF2 (fast, embedded text)
  2. PyMuPDF (handles layouts PyPDF2 misses)
  3. Tesseract OCR (image-based PDFs)

Quality Scoring:
  - Character validity ratio
  - Garbage character detection
  - Readability analysis (common words, sentence structure)
  - Encoding health verification
  - Word count and completeness metrics
  - Configurable acceptance thresholds

PDF Type Detection:
  - TEXT_EMBEDDED: Pure text PDFs (fast extraction)
  - IMAGE_BASED: Scanned documents (OCR required)
  - MIXED: Combination of text and images
  - COMPLEX_LAYOUT: Multi-column, rotated, or unusual structures

Benchmarking:
  - Compares all three extraction methods
  - Measures accuracy, speed, and failure rates
  - CSV output for analysis
  - Summary statistics printed to console

================================================================================
GETTING STARTED
================================================================================

1. Install dependencies:
   pip install -r requirements.txt

2. Install system dependency (Tesseract OCR):
   Ubuntu/Debian: sudo apt-get install tesseract-ocr
   macOS: brew install tesseract
   Windows: Download from UB-Mannheim/tesseract GitHub releases

3. Basic usage:
   from extractor import extract_text
   result = extract_text("document.pdf")
   print(f"Text: {result.text[:200]}")
   print(f"Method: {result.method_used}")
   print(f"Confidence: {result.confidence_score:.2%}")

4. Run tests:
   pytest tests/ -v

5. Run benchmarks:
   python benchmark.py --directory ./pdfs --output results.csv
